Utilizar o sensor de campo magnético (magnetômetro) do celular para detectar um ímã físico de verdade é uma ideia genial! Isso transforma a simulação em um experimento prático com física real e tátil, aumentando muito o engajamento dos alunos. Como o magnetômetro mede o campo magnético real ao redor do aparelho (em microteslas, μT), a taxa de CPM do "detector Geiger" pode ser calculada com base na intensidade do campo magnético detectado no instante. 🔬 Como funciona a Física no Celular Campo Magnético Ambiente (Terra): O celular sempre detecta o campo magnético terrestre, que varia entre 30μT e 60μT. Esse valor servirá perfeitamente como o Background (Radiação de Fundo) no seu app. Aproximação do Ímã: À medida que o aluno aproxima o celular de um ímã (escondido sob uma mesa, dentro de uma caixa ou sob um livro), a intensidade total do campo (B) aumenta drasticamente. Mapeamento B→CPM: Convertemos a leitura do sensor magnético em uma taxa de CPM correspondente para a simulação. 💻 Como implementar no navegador (Web Sensors API) Os navegadores mobile modernos suportam a API de Magnetometer. Para garantir compatibilidade com dispositivos mais antigos ou iOS, também usaremos o evento deviceorientation / devicemotion. Abaixo está o código JavaScript necessário para ler o sensor real do celular e alimentar a sua simulação de Poisson: JavaScript let rawB = 40; // Valor padrão inicial em microteslas (µT) let magnetometerActive = false; // 1.
